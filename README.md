# Case Study 11: UI Animation Sorting Visualization

## Objective
Demonstrate sorting step-by-step in educational tools using C++.

## Data Context
- **Dataset**: Small dataset (visual elements).
- **Algorithm**: Bubble Sort (used for step-wise swapping visibility).

## Deliverables
- **Animated transitions**: Terminal-based bar visualization with color highlighting.
- **Swap count**: Real-time tracking of swaps.

## How to Run
1. Navigate to the `miniproject` directory.
2. Compile the code:
   ```bash
   g++ -std=c++11 project1.cpp -o output/project1
   ```
3. Run the visualization:
   ```bash
   ./output/project1
   ```

## Outcomes
- **Easy to visualize**: Bar charts make it intuitive to see how elements move.
- **Teaching Tool**: Useful for demonstrating the inner workings of sorting algorithms.
